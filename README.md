\# Banking System Database 🏦



\## Overview

A relational database project built with MySQL to simulate a simple banking system.  

It manages customers, accounts, transactions, and loans with business rules like deposits, withdrawals, and balance updates.



\## Features

\- Customer management (basic details and contact info)

\- Account management (Savings and Checking accounts)

\- Transaction tracking (Deposits, Withdrawals, Transfers)

\- Loan management (amount, interest rate, duration)

\- Business rules for balance updates and transaction history
